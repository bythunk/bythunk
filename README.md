## What this is

> **thunk** */θʌŋk/* — in compiler science, a computation wrapped and held until it is needed.

Thunk builds software for Apple platforms: iOS, macOS, iPadOS and watchOS. Native Swift, no cross-platform layers, with machine learning that runs on the device rather than on someone else's server.

The bet is simple. Apple Silicon can now run capable models locally. That means software that is private by construction, works without a connection, has no per-token cost, and responds at a speed no round trip can match. Most of the industry is still shipping web views wrapped in an app icon.

## Technical focus

**Language and platform** — Swift 6, SwiftUI, strict concurrency, Swift macros, SwiftPM

**On-device intelligence** — Foundation Models, Core AI, Core ML, Vision, Neural Engine profiling

**Low-level compute** — Metal, Metal Performance Shaders, MLX

**Sensors and capture** — AVFoundation, Core Motion, HealthKit, watchOS, multi-device synchronisation

## How we publish

Measurements, not opinions. Every performance claim in this organisation comes with the method used to produce it and enough sample code to reproduce it.

Technical write-ups and benchmarks go to [X](https://x.com/bythunk) and [YouTube](https://www.youtube.com/@ByThunk). Finished work and design goes to [Instagram](https://www.instagram.com/bythunk/) and [TikTok](https://www.tiktok.com/@thunkstudio).
